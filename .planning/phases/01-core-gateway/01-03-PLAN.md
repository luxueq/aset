**Objective:** 实现智能路由引擎（4 种策略）、自动 Failover、负载均衡、API Key 管理和认证中间件。

**Must Haves:**

### Task 3.1: Router Engine with 4 Strategies

**Type:** execute

**Action:**
Implement the router engine with pluggable strategy pattern.

```go
// internal/router/router.go
type Strategy interface {
    Select(providers []*ProviderStatus, req *CanonicalRequest) (*ProviderStatus, error)
}

type Router struct {
    strategies map[string]Strategy
    config     RouterConfig
}

// Strategies: roundrobin, latency, cost, weighted
type RoundRobinStrategy struct{}
type LatencyStrategy struct{}     // 按最近延迟排序
type CostStrategy struct{}         // 按模型单价排序
type WeightedStrategy struct{}     // 按权重比例分配
```

Router config example:
```yaml
routing:
  default_strategy: roundrobin
  routes:
    - model: "gpt-4"
      providers: ["openai", "azure-openai"]
      strategy: cost
    - model: "claude-3-opus"
      providers: ["anthropic"]
      strategy: roundrobin
```

- `.planning/phases/01-core-gateway/01-CONTEXT.md` §路由与 Failover (D-08~D-12)

**acceptance_criteria:**
- `internal/router/router.go` defines `Strategy` interface and `Router` struct
- 4 strategies implemented: `RoundRobinStrategy`, `LatencyStrategy`, `CostStrategy`, `WeightedStrategy`
- Router selects correct provider based on model name from request
- Round-robin cycles through providers evenly (verified by 100-request test)

### Task 3.2: Failover + Load Balancing

**Type:** execute

**Action:**
Implement automatic failover and load balancing with health monitoring.

```go
type ProviderStatus struct {
    Name        string
    Healthy     bool
    AvgLatency  time.Duration
    ErrorRate   float64
    Weight      int
    CostPerM    float64
    LastCheck   time.Time
}

type FailoverConfig struct {
    Enabled       bool `yaml:"enabled"`
    MaxAttempts   int  `yaml:"max_attempts"`   // 默认 3
    ReturnOnError bool `yaml:"return_on_error"` // false = auto failover, true = return error
}

func (r *Router) Route(ctx context.Context, req *CanonicalRequest) (*ProviderStatus, []ProviderFailover, error) {
    attempts := 0
    for attempts < r.failover.MaxAttempts {
        provider := r.strategy.Select(r.providers, req)
        resp, err := r.tryProvider(ctx, provider, req)
        if err == nil {
            return provider, nil, nil
        }
        r.recordFailure(provider, err) // 更新错误率
        attempts++
    }
    return nil, allAttempts, ErrAllProvidersFailed
}
```

Health monitoring:
- Active: goroutine pings each provider's /models endpoint every 30s
- Passive: track error rate from real requests (sliding window 5min)
- Unhealthy if: error rate > 50% OR 3 consecutive health check failures

**read_first:**
- `.planning/phases/01-core-gateway/01-CONTEXT.md` §路由与 Failover (D-10~D-12)

**acceptance_criteria:**
- Primary provider failure triggers automatic retry on next provider
- Max 3 attempts before returning `ErrAllProvidersFailed`
- `return_on_error: true` returns error to client instead of failover
- Provider error rate tracked from real requests (sliding window)
- Active health check marks provider unhealthy after 3 consecutive failures
- Unhealthy provider excluded from routing until recovery

### Task 3.4: Auth Middleware

**Type:** execute

**Action:**
Implement Bearer Token authentication middleware that validates API keys and sets request context.

```go
// internal/auth/middleware.go
func AuthMiddleware(keyService *KeyService) func(http.Handler) http.Handler {
    return func(next http.Handler) http.Handler {
        return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
            auth := r.Header.Get("Authorization")
            if !strings.HasPrefix(auth, "Bearer ") {
                writeError(w, http.StatusUnauthorized, "missing_bearer_token")
                return
            }
            token := strings.TrimPrefix(auth, "Bearer ")
            key, err := keyService.Validate(r.Context(), token)
            if err != nil {
                writeError(w, http.StatusUnauthorized, "invalid_api_key")
                return
            }
            // Set request context with key info
            ctx := context.WithValue(r.Context(), authContextKey, key)
            next.ServeHTTP(w, r.WithContext(ctx))
        })
    }
}
```

Skip auth for health check endpoints (`/health`, `/ready`).

**read_first:**
- `.planning/phases/01-core-gateway/01-CONTEXT.md` §Provider 适配策略 (D-06)

**acceptance_criteria:**
- Request without `Authorization: Bearer <key>` returns 401
- Request with valid key passes through, context contains key info
- Request with revoked key returns 401
- Request with expired key returns 401
- `/health` and `/ready` endpoints skip auth (return 200 without key)
- Permission check: key without `embeddings` permission rejected for `/v1/embeddings`
