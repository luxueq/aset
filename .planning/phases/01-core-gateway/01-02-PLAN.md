**Objective:** 建立 Provider 适配器框架，实现 OpenAI 和 Anthropic 两个提供商的适配，支持请求/响应格式归一化和流式转发。

**Must Haves:**
- Provider interface 定义
- OpenAI adapter 实现

- 错误格式统一为 OpenAI 风格
- 不支持参数 drop + 可配置严格模式

### Task 2.3: Anthropic Adapter Implementation

**Type:** execute

**Action:**
Implement the Anthropic adapter that converts between Anthropic Messages API and canonical OpenAI format.

Key conversions:
- Request: `messages` array → Anthropic `messages` + `system` extraction
- Response: `content_block_delta` events → OpenAI `choices[0].delta` format
- Usage: `input_tokens`/`output_tokens` → `prompt_tokens`/`completion_tokens`
- Model mapping: `anthropic/claude-3-opus` → `claude-3-opus-20240229`

```go
func (a *AnthropicAdapter) ConvertRequest(ctx context.Context, req *CanonicalRequest) (*http.Request, error) {
    anthropicReq := AnthropicRequest{
        Model:       stripProviderPrefix(req.Model), // "anthropic/claude-3-opus" → "claude-3-opus"
        Messages:    convertMessages(req.Messages),
        MaxTokens:   req.MaxTokens,
        Stream:      req.Stream,
    }
    // Extract system message from messages array
    if len(req.Messages) > 0 && req.Messages[0].Role == "system" {
        anthropicReq.System = req.Messages[0].Content
        anthropicReq.Messages = req.Messages[1:]
    }
}
```

### Task 2.5: Automatic Retry with Specific Status Codes

**Type:** execute

**Action:**
Implement retry logic for specific HTTP status codes (429, 500, 502, 503) with exponential backoff.

```go
type RetryConfig struct {
    MaxRetries     int           `yaml:"max_retries"`     // 默认 3
    RetryOn        []int         `yaml:"retry_on"`        // [429, 500, 502, 503]
    InitialBackoff time.Duration `yaml:"initial_backoff"` // 500ms
    MaxBackoff     time.Duration `yaml:"max_backoff"`     // 30s
}

func (p *Proxy) doWithRetry(ctx context.Context, req *http.Request) (*http.Response, error) {
    for attempt := 0; attempt <= p.retryConfig.MaxRetries; attempt++ {
        resp, err := p.httpClient.Do(req)
        if err != nil {
            continue
        }
        if !shouldRetry(resp.StatusCode) {
            return resp, nil
        }
        resp.Body.Close()
        backoff := calculateBackoff(attempt)
        select {
        case <-time.After(backoff):
        case <-ctx.Done():
            return nil, ctx.Err()
        }
    }
}
```
