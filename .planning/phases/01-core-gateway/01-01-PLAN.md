### Task 1.2: Configuration Loading with Viper

**Type:** execute

**Action:**
Implement configuration loading using Viper. Support YAML and TOML formats with environment variable override for infrastructure settings.

```go
// internal/common/config/config.go
type Config struct {
    Server    ServerConfig    `yaml:"server"`
    Providers ProviderConfigs `yaml:"providers"`
    Logging   LoggingConfig   `yaml:"logging"`
    Database  DatabaseConfig  `yaml:"database"`
    Redis     RedisConfig     `yaml:"redis"`
}

func Load(cfgFile string) (*Config, error) {
    v := viper.New()
    v.SetConfigFile(cfgFile)
    v.AutomaticEnv()
    v.SetEnvPrefix("AIGATEWAY")
    // ... load and unmarshal
}
```

Bind environment variables for infrastructure:
- `AIGATEWAY_SERVER_PORT` → `server.port`
- `AIGATEWAY_DATABASE_URL` → `database.url`
- `AIGATEWAY_REDIS_URL` → `redis.url`

### Task 1.3: Structured Logging with zap

**Type:** execute

**Action:**
Implement structured JSON logging using `go.uber.org/zap`. Create a logger package that reads config and provides a global logger.

```go
// internal/common/logger/logger.go
func Init(cfg LoggingConfig) (*zap.Logger, error) {
    var cfg zap.Config
    if cfg.Format == "json" {
        cfg = zap.NewProductionConfig()
    } else {
        cfg = zap.NewDevelopmentConfig()
    }
    cfg.Level = zap.NewAtomicLevelAt(parseLevel(cfg.Level))
    return cfg.Build()
}
```

Use `logger.Info("request completed", zap.String("method", "POST"), zap.Int("status", 200))` pattern.

### Task 1.5: Health Check and Graceful Shutdown

**Type:** execute

**Action:**
Implement `/health` and `/ready` endpoints and graceful shutdown logic.

```go
// /health - always returns 200 if process is alive
// /ready - checks DB/Redis connectivity before returning 200

func gracefulShutdown(server *http.Server) {
    ctx, stop := signal.NotifyContext(context.Background(), syscall.SIGTERM, syscall.SIGINT)
    defer stop()
    <-ctx.Done()
    setUnhealthy()
    time.Sleep(5 * time.Second) // let LB drain
    shutdownCtx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
    defer cancel()
    server.Shutdown(shutdownCtx)
}
```
