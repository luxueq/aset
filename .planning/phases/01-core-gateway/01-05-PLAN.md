### Task 5.1: Cache Key Computation

**Type:** execute

**Action:**
Implement smart cache key computation: model + messages + key params (temperature, seed).

```go
// internal/cache/key.go
type KeyConfig struct {
    IncludeFields []string `yaml:"include_fields"` // 默认: ["model", "messages", "temperature", "seed"]
    IgnoreFields  []string `yaml:"ignore_fields"`  // 可配置忽略的字段
}

func ComputeCacheKey(req *CanonicalRequest, cfg KeyConfig) string {
    h := sha256.New()
    h.Write([]byte(req.Model))
    for _, msg := range req.Messages {
        h.Write([]byte(msg.Role))
        h.Write([]byte(msg.Content))
    }
    if req.Temperature != nil {
        fmt.Fprintf(h, "t:%.2f", *req.Temperature)
    }
    if req.Seed != nil {
        fmt.Fprintf(h, "s:%d", *req.Seed)
    }
    return hex.EncodeToString(h.Sum(nil))
}
```

### Task 5.2: L1 Local Memory Cache + L2 Redis Cache

**Type:** execute

**Action:**
Implement two-layer caching: L1 local memory (hot data, LRU) + L2 Redis (shared, TTL).

```go
// internal/cache/cache.go
type Cache struct {
    l1    *LRUCache     // 本地内存，同步
    l2    *RedisCache   // Redis，网络
    ttl   time.Duration // 默认 5 分钟
}

func (c *Cache) Get(ctx context.Context, key string) (*CachedResponse, bool, error) {
    // L1 查找
    if resp, ok := c.l1.Get(key); ok {
        return resp, true, nil
    }
    // L2 查找
    resp, err := c.l2.Get(ctx, key)
    if err != nil {
        return nil, false, err
    }
    if resp != nil {
        c.l1.Set(key, resp) // 回填 L1
        return resp, true, nil
    }
    return nil, false, nil
}

func (c *Cache) Set(ctx context.Context, key string, resp *CachedResponse) error {
    c.l1.Set(key, resp)
    return c.l2.Set(ctx, key, resp, c.ttl)
}
```

LRU with `hashicorp/golang-lru/v2`:
```go
type LRUCache struct {
    cache *lru.Cache[string, *CachedResponse]
}
```

**read_first:**
- `.planning/phases/01-core-gateway/01-CONTEXT.md` §缓存架构 (D-13, D-16)
- `.planning/phases/01-core-gateway/01-RESEARCH.md` §3 (Semantic Caching)

**acceptance_criteria:**
- L1 hit: response returned without Redis call (< 1ms)
- L1 miss + L2 hit: response returned from Redis, L1 backfilled (< 10ms)
- L1 miss + L2 miss: cache miss, caller fetches from provider
- L2 entries expire after TTL (default 5 minutes, configurable)
- L1 evicts LRU entries when at capacity (configurable max items)
- `DELETE /v1/cache/clear` clears both L1 and L2

### Task 5.3: Cache Middleware Integration

**Type:** execute

**Action:**
Integrate cache as middleware in the request pipeline. Add `X-Cache: HIT/MISS` header.

```go
func CacheMiddleware(cache *Cache) func(http.Handler) http.Handler {
    return func(next http.Handler) http.Handler {
        return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
            // 只对非流式请求缓存（流式请求不缓存，因为需要实时性）
            if isStreaming(r) {
                w.Header().Set("X-Cache", "MISS")
                next.ServeHTTP(w, r)
                return
            }

            key := computeCacheKey(r)
            resp, hit, err := cache.Get(r.Context(), key)
            if hit && err == nil {
                w.Header().Set("X-Cache", "HIT")
                w.Header().Set("Content-Type", "application/json")
                json.NewEncoder(w).Encode(resp)
                // Record cache hit metric
                return
            }

            // Cache miss: wrap response writer to capture response
            recorder := &responseRecorder{ResponseWriter: w, body: &bytes.Buffer{}}
            w.Header().Set("X-Cache", "MISS")
            next.ServeHTTP(recorder, r)

            // Store in cache
            if recorder.StatusCode == 200 {
                cache.Set(r.Context(), key, parseResponse(recorder.body))
            }
        })
    }
}
```

**read_first:**
- `.planning/phases/01-core-gateway/01-CONTEXT.md` §缓存架构 (D-17~D-18)

**acceptance_criteria:**
- Non-streaming request: cache hit returns `X-Cache: HIT` header
- Non-streaming request: cache miss returns `X-Cache: MISS` header
- Streaming requests: always `X-Cache: MISS` (not cached)
- Second identical request returns cached response
- Manual cache clear via API works

### Task 5.4: Semantic Cache

**Type:** execute

**Action:**
Implement semantic cache using embedding vector similarity search.

```go
// internal/cache/semantic.go
type SemanticCache struct {
    embedder    Embedder
    vectorDB    VectorDB
    threshold   float64 // 默认 0.92
    ttl         time.Duration
}

type Embedder interface {
    Embed(ctx context.Context, text string) ([]float64, error)
}

type VectorDB interface {
    Search(ctx context.Context, embedding []float64, threshold float64) (*VectorResult, error)
    Store(ctx context.Context, key string, embedding []float64, response []byte, ttl time.Duration) error
}
```

Flow:
1. Extract messages content from request
2. Call embedding model to get vector
3. Search vector DB for similar cached responses
4. If similarity > threshold → return cached response
5. If no match → proceed to LLM, then store result in vector DB

Embedding model: configurable (default OpenAI `text-embedding-3-small`, or local model).
